# Catatin — Landing Page

Landing page untuk **Catatin**, aplikasi catat keuangan pribadi & UMKM.

Website statis: HTML, CSS, dan JavaScript murni, tanpa build step dan tanpa dependency.

## Struktur

```
.
├── index.html      # Halaman utama
├── css/
│   └── style.css   # Seluruh styling
└── js/
    └── script.js   # Navigasi, tema gelap/terang, FAQ, toggle harga, animasi
```

## Menjalankan secara lokal

Buka `index.html` langsung di browser, atau jalankan server lokal:

```bash
npx serve .
# atau
python -m http.server 8000
```

## Sebelum live

- Ganti gambar placeholder (`placehold.co`) dengan screenshot dan foto asli.
- Ganti nomor WhatsApp (`wa.me/6281234567890`) dan email kontak dengan data asli.
- Perbarui link media sosial di footer.
